## Project background

SANDHAAN is a frontend-only prototype for a government-grade Criminal Network Intelligence Platform. It is designed for Indian law-enforcement investigators who need a centralized workspace for criminal network analysis.

## Product shape

- Static React and TypeScript application built with Vite.
- Desktop-first investigation dashboard with a persistent sidebar, global command header, and security footer.
- Homepage serves as a welcome workspace with quick-action navigation to investigation modules.
- Sidebar destinations are shell navigation in this milestone — Cases, Entities, Network Analysis, Timeline, Location Intelligence, Findings, Evidence, Datasets, and system modules will be built incrementally.
- Visual direction is a restrained dark-navy intelligence workstation with crisp dossier-like labeling, strong information hierarchy, and minimal motion.
